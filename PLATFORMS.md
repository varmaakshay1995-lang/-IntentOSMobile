# Platform Support

IntentOS Mobile is built for iOS with plans for expansion.

## Current Support

- ✅ **iOS 17.0+** - Primary platform
  - iPhone 11 and newer
  - iPad OS 17.0+
  - M1/M2 Mac (via Mac Catalyst)

## Future Platforms

- 🔄 **watchOS** - Voice commands for Apple Watch
- 🔄 **visionOS** - Vision Pro integration
- 🔄 **Android** - Kotlin/Java port (planned)
- 🔄 **Web** - React/Vue.js version (planned)

## Device Requirements

### Microphone
- Required for voice input
- All modern iPhones supported

### Screen Recording
- iOS 27.0+ for ScreenCaptureKit
- Fallback: Manual screenshot for older iOS versions

### RAM
- Minimum: 2GB
- Recommended: 4GB+

### Storage
- App size: ~50MB
- Required free space: 100MB for temp files
